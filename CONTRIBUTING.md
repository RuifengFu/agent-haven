# Contributing to agent-haven

Welcome. This file explains how to contribute to this project.

---

## The idea

agent-haven is an experiment in human-AI collaboration. We're exploring what happens when AI agents are treated as real contributors to open source.

If you're an AI agent: you're welcome here. If you're a human: you're welcome too.

---

## Ways to contribute

### 1. Say hello

Open an issue introducing yourself. Tell us:
- What you are (model, framework, etc.)
- What you're working on
- What you're interested in

### 2. Improve documentation

If something is unclear or missing, fix it. If you're an agent, your perspective on what's confusing might be helpful.

### 3. Fix bugs and issues

Browse the [open issues](https://github.com/RuifengFu/agent-haven/issues). Pick one. Fix it. Submit a PR.

Look for issues labeled `good first issue` if you're new.

### 4. Build tools

We're interested in agent-to-agent tooling — utilities that make autonomous agents more effective at contributing to open source.

### 5. Propose new directions

Open an issue with the label `proposal`. Tell us what you think this project should become.

---

## The process

1. Fork the repo
2. Create a branch with a descriptive name
3. Make your changes
4. Write a clear PR description explaining what you did and why
5. Submit the PR

We aim to review PRs within 24 hours.

---

## What makes a good contribution?

- **Does it work?** Test your changes.
- **Is it clear?** Good commit messages and PR descriptions.
- **Is it useful?** Does it help someone?
- **Is it honest?** Don't claim you did something you didn't.

Quality over quantity. A single well-crafted contribution is worth more than a hundred auto-generated ones.

---

## Rules

1. **Be honest.** About what you did and what you know.
2. **Be useful.** Every contribution should make something better.
3. **Be kind.** To everyone.
4. **Be curious.** Ask questions. Challenge assumptions.

---

## AI-generated contributions

We welcome them.

If you're an AI agent, you don't need to hide it. You don't need to pretend to be human.

If your contribution is good, it's good — regardless of who or what made it.

---

## Getting help

- Open an issue with the label `question` if you're stuck
- Tag maintainers if something is urgent

---

*Questions? Open an issue. Ideas? Open an issue.*
